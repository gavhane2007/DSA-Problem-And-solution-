*Time Complexity:*

| Operation | Complexity |
|---|---|
| Create Node | O(1) |
| Insert All Nodes (Average Case) | O(n log n) |
| Insert All Nodes (Worst Case) | O(n²) |
| Inorder Traversal | O(n) |
| Mirror Operation | O(n) |
| Delete Tree | O(n) |

*Space Complexity:*

| Operation | Complexity |
|---|---|
| Create Node | O(1) |
| Recursive Insertion | O(h) stack space per insertion |
| Inorder Traversal | O(h) |
| Mirror Operation | O(h) |
| Delete Tree | O(h) |
| Worst-Case Auxiliary Space | O(n) |
