# Food Order Management Using Linked List

## Project Description
A Food Order Management System implemented using a Singly Linked List in C++.

## Data Structure Used
Singly Linked List

## Operations
- Add New Order
- Display Orders
- Place/Complete Order
- Delete First Order

## Working
Each food order is stored as a node. New orders are inserted at the end of the linked list. When an order is completed, the first node is deleted.

## Example
HEAD → Order 101 → Order 102 → Order 103 → NULL
